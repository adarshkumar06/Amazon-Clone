# Amazon-Clone 🛒

This repository contains a frontend-only clone of the Amazon website, created using HTML and CSS. The goal of this project is to replicate Amazon's user interface to practice and showcase my web development skills.

## Features ✨
 **Responsive Design:** The layout adjusts to different screen sizes for a seamless experience across devices.
- **Navigation Bar:** Includes a search bar, category links, and account options, styled to resemble the original.
- **Product Grid:** Displays product items in a grid layout, similar to Amazon’s product listings.
- **Footer Section:** Contains essential links, policies, and other site information.
- **Hover Effects:** Interactive UI elements like buttons and links styled with **CSS hover effects**.
  
## Technologies Used 🛠️
HTML5: For structuring the webpage.
CSS3: For styling, layout, and responsiveness.
